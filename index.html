§ 01 — Now

A full-stack side project, built in public.

Personal Project · 2024 → Present

Doctor AI

An iOS + Android consultation tool that uses LLMs to generate structured clinical notes from doctor–patient conversations. Solo-built across six repositories: Swift/SwiftUI client, Android companion, shared Swift Package, a TypeScript + Node.js backend on Google App Engine, and an evaluation notebook for prompt iteration.

The interesting parts: speaker diarization for attributing turns in the transcript, Twilio Video for secure calls, Apple Speech for on-device transcription, and LLM orchestration server-side so prompts can be versioned without shipping new iOS builds.
