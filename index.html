Personal Project · Jan 2024 → Present

Doctor AI

An iOS + Android consultation tool that uses LLMs to generate structured clinical notes from doctor–patient conversations. Solo-built across six repositories: a Swift/SwiftUI client, an Android companion, a shared Swift Package (AIDoctor-SPM), a TypeScript + Node.js backend on Google App Engine, and an evaluation notebook for prompt iteration.

The interesting parts: Twilio Video for secure doctor–patient calls, Apple Speech for on-device transcription, and server-side LLM orchestration so prompts can be versioned without shipping a new iOS build. Firebase (Auth, Firestore, FCM) covers identity, realtime data, and push for the beta cohort. A Jupyter notebook handles model evaluation between prompt iterations.

Personal Project · March 2026 → Present

CarSales Bot

An AI-driven WhatsApp sales assistant for car dealerships, shipped as a signed and notarized desktop app (macOS DMG, Linux .deb / AppImage) so non-technical dealers can install it themselves. The system pairs to a dealership's WhatsApp number, answers inventory questions through an OpenAI tool-calling agent, sends vehicle photos and videos as native attachments, and keeps the catalog fresh via a scheduled scraping daemon — replacing hours of repetitive sales-rep messaging with a 24/7 first-line bot that qualifies leads and routes serious buyers to a human.

The interesting parts: a 3-tier service layout (Repository → Service → Adapter) cleanly separates the Baileys WhatsApp transport, the agent loop, and the SQLite inventory; pluggable scraper adapters (cheerio + undici) feed the catalog; QR pairing is rendered as SVG in the Electron main process and piped over IPC to a sandboxed renderer (contextIsolation: true, nodeIntegration: false); electron-builder produces arm64/x64 DMGs with Developer ID signing + notarization, with electron-updater wired to GitHub Releases for OTA. 290+ Vitest tests, strict TypeScript end-to-end, and a companion license server for dealer-key issuance. On macOS: menu-bar status glyphs, Notification Center alerts, and login-item auto-start.
